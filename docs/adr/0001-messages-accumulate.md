# Messages accumulate; Incidents are not mutated

JESIP builds shared awareness from successive M/ETHANE messages, not from overwriting a living form. We persist and SEND a Message; an Incident is only a grouping id.

A mutating Incident document would make confirm/SEND ambiguous and turn the stretch (second clip) into a merge problem we will not finish in one day. Stretch is a second Message on the same Incident, with a diff — not a patch.
