# A local model fills Slots from the Transcript; the officer is not replaced

The product’s job is to turn free speech into a Message so the officer need not type or recite M/ETHANE in order. Keyword rules cannot carry that claim.

After ASR, unload Parakeet, then a tiny local model writes Slot values and Provenance from the Transcript via JSON schema. Keyword rules are a crash fallback so the demo is not zero if the model dies — they are not the pitch. The model still must not invent Coordinates, must not declare Major incident Yes from scale, and must not silently promote Provenance.
